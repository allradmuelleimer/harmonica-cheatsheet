Harmonica Cheatsheet for Windows

Privacy Policy

Last updated: 20 November 2026 · Deutsch

In short

Harmonica Cheatsheet for Windows is a reference app for harmonica players. Everything is computed and drawn on your computer. The app makes no network connections, has no developer server, no user account, no advertising and no analytics. It does not use the microphone. No personal data is collected, stored or transmitted by the app.

What is stored on your computer

Your settings (for example language, colours, zoom, window size and, if you switch it on, the last view you had open) are saved in a small settings file in your Windows user profile. The file never leaves your computer. Uninstalling the app removes it.

Microsoft Store

The app is distributed through the Microsoft Store. Downloading, purchasing, updates and any crash or usage reports that Windows itself sends are handled by Microsoft under the Microsoft Privacy Statement. The developer receives only the aggregated, anonymous statistics that Microsoft shows every publisher (such as download numbers) and no personal data about you.

Children

The app does not collect data from anyone, including children.

Changes

If the app ever starts to process personal data, this page will be updated before that version is published.

Kurz gesagt

Harmonica Cheatsheet für Windows ist ein Nachschlagewerk für Mundharmonikaspieler. Alles wird auf deinem Rechner berechnet und gezeichnet. Die App baut keine Netzwerkverbindungen auf, hat keinen Server des Entwicklers, kein Benutzerkonto, keine Werbung und keine Analyse-Werkzeuge. Sie benutzt kein Mikrofon. Die App erhebt, speichert und überträgt keine personenbezogenen Daten.

Was auf deinem Rechner gespeichert wird

Deine Einstellungen (etwa Sprache, Farben, Zoom, Fenstergröße und – wenn du es einschaltest – die zuletzt geöffnete Ansicht) liegen in einer kleinen Einstellungsdatei in deinem Windows-Benutzerprofil. Sie verlässt deinen Rechner nie und wird beim Deinstallieren entfernt.

Microsoft Store

Die App wird über den Microsoft Store verteilt. Herunterladen, Kauf, Updates sowie Absturz- und Nutzungsberichte, die Windows selbst sendet, wickelt Microsoft nach der Datenschutzerklärung von Microsoft ab. Kinder
